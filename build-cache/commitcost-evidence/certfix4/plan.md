# CERTFIX4 boundary review and plan

Adversary: an ordinary publication inserts a disposable cold content/tree build over every occupied row or history. It must be uncallable without the sealed reconstruction capability, and every genuine reconstruction uses the original Execution request before traversal/allocation.

## Boundary findings

The canonical content owner accepts Option<predecessor> and branches into whole-arena construction. Its record and adjacency owners repeat that branch; history hashing also accepts an optional old arena. Head-frontier admission, resident verification and checkpoint capture all reach the same lane-free engine. DigestIndex has a crate-visible sorted cold constructor below its public lane-taking cold entrance. Kind construction already requires the lane, but nested owning helpers and history verification/folding must be included in the caller census. Generic persistent containers and explicit query/retention walks are distinct from full commitment construction and will be listed rather than mislabeled as protected.

The original request is authoritative. No engine may mint a lane or vend one through a callback. Registered actual trust-boundary operations may mint locally and retain the capability. Public diagnostic/recovery callers must thread their request rather than manufacture an unfunded request inside a helper.

1. Census every storage/index whole-structure function and trace matching functions in durability, branch and publication dependencies. Save raw grep evidence and commit the reviewed census with counts.
2. Replace optional-predecessor content capture with separate predecessor-required maintenance and lane/request-funded cold/full/layered/head reconstruction. Split record, history and adjacency cold engines from maintenance; require the lane on sorted commitment construction and all full-capture engines. Keep hashing bytes unchanged.
3. Thread original admission from cold restore/checkpoint/verification and first-region boundaries. Propagate required types through tests mechanically; retain their fixtures, assertions, scales and thresholds.
4. Replay unchanged A–L reviewer operators and add lane-free compile probes for each engine sealed. Restore every mutated file by SHA-256 and rebuild restored artifacts.
5. Run Native, SDK/SC cost, Query/root affected evidence, boundary/context, formatting, caps and whitespace. Compare against accepted clean master census; no new baseline target unless new evidence requires it. Commit once, report CERTFIX4 and READY-FOR-MERGE, then stop.
