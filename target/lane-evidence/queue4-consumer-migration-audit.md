## Decision

There is a concrete owner-area conflict before full adapter retirement: the user requires `branch/root_*` to remain untouched, but two files in that area consume the local provider being retired. Neither an external provider substitution nor an existing public path can keep those local-Native tests compiling without editing their callers. Stop this item at the named area edge and obtain the owner handoff; do not use another local adapter, memory substitution, baseline growth, macro, alias, generic conversion or changed test mounting to avoid it.

This conclusion does **not** depend on file size, Weak syntax or a claim that public observations are generally inadequate. The five exact private claims retired by grant 12 remain the only authorized assertion retirements. No additional assertion retirement is proposed here.

The baseline may not gain roots or rows.

Respect the registered court frontier and the 15,000-line court/testkit ceiling while assigning migration families. A large candidate inventory does not itself justify another dependency surface; split on the next genuine responsibility axis where the ceiling requires it. Preserve test names/multisets except the five explicit grant-12 retirements and convention-required milestone-name stripping; record those changes explicitly.
