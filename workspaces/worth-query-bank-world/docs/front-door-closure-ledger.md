# Bank World Front-Door Closure Ledger

## Closure rule

`PROVED` requires a named production owner, a positive witness, a hostile twin
where the claim has a denial boundary, an independent oracle, a consequential
assertion, and the cheapest exact command. `OPEN` means the guarantee is
currently reachable but not yet proved. `DEFECT` means present source violates
the guarantee. `BLOCKED` names the earlier guarantee or later phase whose
unavailable behavior makes honest proof impossible. A green test alone does
not close a row. A high- or critical-impact finding reopens every row it can
invalidate.
