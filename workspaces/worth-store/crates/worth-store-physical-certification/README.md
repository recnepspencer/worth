# worth-store-physical-certification

Owns Roadmap 2 S.12: reproducible physical certification bundles, hostile
fault injection, bounded-memory proof, recovery-time proof, I/O interference
proof, blob-scale proof, backend capability matrices, and hazard analysis.

This crate certifies the physical database substrate before platform roadmap
claims resume.

The C9 64 KiB page producer admits an 18 MiB operation envelope. Final-matrix
measurement found its second batch's 202-page planning reservation (13,238,272
bytes) overlapping 4,666,496 retained bytes, totaling 17,904,768 bytes. The
envelope rounds that overlap up to the next whole MiB (18,874,368 bytes).
Other profiles retain 16 MiB. Each producer reports and checks its operation
peak; the four-page resident limit and eviction assertions remain in force.
