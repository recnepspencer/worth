## Boundary review

Execution owns process workers, lease lineage and native execution. Query owns
tracked membership, reads, canonical partition association, retained results and
publication. Declaration owns canonical serialization, ordering and identity.
Numerical workers receive values and checkpoints; completing a value grants no
publication authority.

Worker-only preparation currently enters the charge-producing canonical encoder.
Query changes its callback into polling, but the encoder still calculates hash,
comparison and scratch charges and constructs canonical-work metadata. This is
ordinary accounting overhead after its bill has been removed. Select polling
before those calculations at the encoder owner. Preserve the existing explicit
accounted contract and all canonical representation and control guarantees.

Retained-call records also carry reached entities, call order and actual custody.
Their accounting fields are already optional. Preserve that evidence rather than
mistake the whole retained-call structure for a bill.

## Decisive proof

The same serialized input, item and key must derive identical identities through
accounted and polling-only encoding, including maps whose iteration order differs.
A serializer that catches a stopped callback and returns success must still
return the original latched stop. An ordinary native partition run must preserve
canonical results under worker placement and reordered completion, retain
unaffected partitions across tracked edits, and release original worker custody.
No comparison of work invoices is an ordinary-mode acceptance requirement.
