## Physical owner

payload byte conversion, live policy and reservation before one fresh pinned
allocator-api2 Global Vec allocation. Non-zero-sized capacity must equal the
admitted logical count. Builders move values without Clone or growth and require
exact fill before sealing. Sized owning iteration retains backing and its linear
reservation until iterator drop, including after exhaustion. Elements/storage
drop before the ticket. Explicit Arc sharing retains one owner and charge.

Zero-sized logical count is distinct from the allocator's capacity. The private
iterator retains its aligned Vec and uses safe pop, avoiding the pinned vendor
iterator's byte-pointer movement for zero-sized elements. Execution empty/ZST
backing carries Some(0); System backing carries None. Byte authoring uses the
same allocation owner while retaining its bounded checksum/copy operations.
Generic ExecutionAllocationPolicy/Denial replace byte-only physical names.

No arbitrary Vec adoption, raw ticket attachment/extraction, mutable array view,
default policy, hidden pool or fallback is introduced.
