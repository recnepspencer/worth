# Historical fields of an actual created source output

This is the next public 9.18 Phase 2 boundary after typed compensation. It supplies
the source-bound identity needed by Bank journal compensation. It does not close
Phase 2 or begin Phases 3–4. Private remains outside the task.

## Reviewed owners and constraints

The actual performed occurrence already retains two complementary facts:

- `WorthQueryApplicationOutputCorrespondence` records the original mutation
  binding and output contract, role, posture, cardinality and full generational
  entity identity from the actual committed candidate.
- `WorthQueryApplicationCommittedChanges` privately owns the same commit's
  immutable canonical envelope and authoritative field patches.

`OutputRoleUse::fixed` checks declared role membership at compile time.
`bound_entity` checks contract, posture, cardinality and entity type, but does not
check the source mutation binding. Projection must separately compare the actual
correspondence binding with the correction's concrete Source binding. Keep that
qualification specific to correction projection: ordinary contract-only output
views intentionally support multiple bindings sharing one output contract.

`ApplicationFieldRef::eq` compares only entity/aspect/field names. It cannot
authorize a historical field witness. The existing field binding recipe retains
portable value-binding identity, scalar family, unit, frame and canonical value
meaning. Installation must resolve and bind the complete field meaning against
the actual schema, rather than accept equal names as equivalent codecs.

The canonical patch helper currently returns cloned values. A private borrowed
projection at that owner can supply original values without adding retained
payload, a live query, a history registry or a cache. Missing or duplicate writes
and unsupported field paths must remain refusals. This first slice supports
exactly-one Create output roles; an unchanged Preserve field and a Retire
pre-image require their own truthful historical material contracts.

Bank's `author_journal` already returns the actual created Journal entity.
`SendMoneyHandler` presently discards that entity and returns the domain JournalId
only as a result. Its binding declares NoApplicationMutationOutputs. The adopter
must declare a real created-Journal role, bind that returned entity, and request
JournalIdentityField as historical material. A guessed ID, result-shaped copy,
client-key lookup or caller Journal selector cannot replace the source witness.

## Contract and placement

Extend the existing correction association with a finite manifest of declared
source-output fields. A declaration-owned typed constructor couples the source
mutation's Output contract, an exactly-one Create role, and a field on that role's
entity and schema. Reuse existing role descriptors and field binding recipes.
Include source/role/field meaning in canonical identity and the existing archive
representation. Preserve untrusted reconstruction followed by native validation;
portable fields never become executable dispatch or proof by themselves.

Installation validates source binding/contract membership, role declaration,
posture/cardinality, entity identity and full field/value meaning through existing
owners. It retains the resolved manifest on the installed correction association.
No second association registry is introduced.

After ordinary fresh disclosure succeeds, native derivation lends a private
read-only material view bound to the exact original occurrence and manifest. Its
object-safe method accepts a declared field witness, never a caller EntityId or
raw locator. Resolve the original role through its actual correspondence, then
read that entity's declared field from the same retained canonical patch.
Domain code decodes through the existing field value binding.

Native projection must preserve liveness/resource causes. Use the existing
execution request when traversing actual source material and preserve its typed
refusal across the domain-callback boundary. Undeclared or mismatched witness
access must disclose no value and cannot be hidden by a callback returning an
otherwise valid intent. Follow existing reader failure propagation, keeping any
local failure state on the borrowed native reader. This is not a new authority or
continuation framework.
