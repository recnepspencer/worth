# Phase 2: conservative public cache under the Native image owner

## Boundary review

Public-only Phase 1 indexes keep ReadyIndex in Query's registration and evict it
through RegisteredDerivedView after World publication. Maintained indexes already
publish through Native's managed companion image. Removing that late updater alone
would leave stale public caches selectable. Compiling every public Source as an
invariant Source would instead reject previously supported query shapes.

Native already retains the exact managed companion image on each genuine selected
snapshot, including a predecessor while Native is ahead of World and an older
ReuseExact component. VisibilityReadContext resolves that snapshot and the current
companion registration. ManagedSourceRootImage owns the corresponding cell affinity.
These owners can issue conservative cache custody without a Source program or
invariant audience. Query continues to own typed installed association, runtime,
principal/scope, World incarnation, ordinary Source READ and provider purpose proof.

Independent review found a retention cycle if ReadyIndex itself enters Native:
its completed Source terminal retains the World observation and therefore the
owning Native root. Split immutable disclosed rows/order and provider nodes from
completed READ custody first. Only that pure material enters the Native directory;
the Query attachment keeps the completed Source terminal and a Native token.
The pure projection tree contains coordinates, disclosed values and nested rows,
not a selected snapshot. Source expectation/result-set/affinity and rebuild loans
remain outside the Native payload. The two sides share the same immutable material
Arc, so this split copies no rows and invents no READ authority.

The managed Native image currently exists only when invariant Sources are installed.
The existing resource installation must also request it for a public provider
catalog. Its publication clone will preserve maintained Source roots and start the
conservative cache directory empty. No cache payload or provider callback runs in
cutover. Forks likewise start their public cache cold; a real retained predecessor
keeps its own directory.

An exact Native-issued cache slot is disposable material, never permission or
interpreted membership. It retains the original payer. Requestless evict/close
must remove that slot without COW allocation and carry payload destruction beyond
all Native runtime, registry and Query state guards. Rebuild retires its previous
slot, so repeated rebuild/close cannot leave an accumulating directory.

## Implementation plan

1. Add a conservative public directory to ManagedIndexBranchImage, separate from
   maintained Source associations. Use a checked per-image slot ordinal and a
   mutable ordered directory. Admit entry, token and conservative node backing
   against the original request before allocation; retain grants with their actual
   owners. Native image cloning starts this directory empty in constant time.
2. Issue and validate an opaque public-cache token only through the actual selected
   snapshot, live companion registration and managed image affinity. Selection
   checks that selected image, not the latest branch head. Retirement removes only
   its exact slot and returns cleanup custody; it allocates nothing. Metadata-only
   head lifecycle status cannot supply READ authority.
   The entry token carries exact Native-issued slot custody. Once selected image,
   registration and affinity match, consume that receipt directly: payload is
   never refilled/replaced and retirement's take linearizes eviction. The retention
   directory is not another READ authority and needs no redundant read lookup.
3. Request the existing managed companion image for public provider catalogs too,
   without lowering unsupported Sources or issuing initialization authority.
4. Separate pure Source material from completed read custody as above. Keep
   ordinary Source acquisition, provider build and purpose proof. Replace
   Query's completed provider-node ownership with the Native cache token. Admit a build
   before installation; reject/retire any result whose registration epoch changed.
   Selection obtains the payload from Native at its actual selected basis before
   provider callbacks. Existing RootEpoch and typed association checks still guard
   a retained selection; no duplicated ordinary root owner remains.
5. Remove ManagedIndexState's RegisteredDerivedView publication implementation and
   registration in the late view list. Keep an independent disposal-only receiver
   for runtime shutdown and preserve the shared registration capacity. Unrelated
   derived views retain their existing updater. Adjust original backing quotes for
   the actual containers that remain.
6. Prove the real public Phase 1 lifecycle first, including close/evict/rebuild and
   an independently scanned Source oracle. Add finite hostile twins for unsupported
   Source compatibility, refused/cancelled publication, actual Native-ahead/World-
   pending selection, sibling/fork/history affinity, and opaque final drop beyond
   owner guards. Reuse existing courts and actual publication controls; do not
   introduce a simulated publisher or a Source authority fallback.
   Closed-caller ruling: this one public lifecycle court may call Query's World
   operation control/active-attempt observation and World's post-owner compare
   pause. These only observe/park its actual installed mutation; they create no
   attempt or publication authority. Add only its exact path to both owner rows.
7. Run focused owner/public courts first, then the existing public managed group and
   required boundary/context/format/size/function gates. The independent reviewer
   applies qa-loop, qa-tests and code-quality-qa before this slice is committed.

The intended user behavior stays the Phase 1 contract: open starts Created, an
authenticated explicit rebuild makes the selected cache Ready, a successful Native
publication makes its successor cold, and an ordinary read never silently rebuilds.
Retained predecessor Source results keep their values. No new consumer API is
required; the new Native token is platform integration custody only.

Whole-registry point lookup and the 1,000/2,000 chain, 50,000 unrelated geometry and
retained-query growth courts remain the next blockers. This slice removes the
managed-index late publication scan; it does not claim the remaining lookup slope
or whole Phase 2 closeout.

## Evidence

The real public prefix Source now uses two disjoint Boolean-guarded paths, a shape
the finite invariant compiler refuses. Its independent seven-row/order/slot oracle
and full public managed group pass (33 tests). Actual cancelled post-Native World
publication retains ProductUnpublished custody: the old World-selected cache still
answers, fresh adoption invokes no provider, and the adopted successor refuses
before callbacks until explicit rebuild.

Three Native owner tests pass: selected predecessor versus cold successor,
cancelled preflight after next-image preparation plus successful twin, and opaque
retirement beyond actual current-image/directory/registration guards. The latter
drops the token before cleanup and all original reservations reach zero. Six
existing managed-cache owner tests pass, including maintained cache retirement,
stale refill and deleted-branch retained affinity. No whole-path growth claim is
made by these courts.
