# Authored retirement: durable current publication ownership (D1124)

Root's D1124 ruling governs this extension of #39/#42 and the D1121 fix round.
The adversarial case is a cold root whose head is an ordinary source edit: every
custody decision must agree with the warm root even when historical envelopes
are unavailable. Dropped, added or re-pointed current roster entries must refuse
with their true publication and record. A successor for another route grants no
custody, including an endpoint retarget.

## Authority and storage boundary

Publication ownership is Native-private current state. It lives in ordinary
region records and relations, with the existing schema, content-digest, checkpoint,
cold kind, publication and record-allocation owners. There is no manifest field,
recovery history demand, second closure engine or producer input-replay contract.
The prior in-memory retained-position prototype is displaced.

An opted-in installation registers private catalog, publication and edge-witness
entity kinds, and scope, publication, member and edge-witness links. Registration
is conditional; independent installations retain their schema and ordinary path.
A catalog is scoped to the actual owning source and lists its current routes and
publication digests. A publication retains the Native origin header and ordinal.
Member links and edge witnesses express the actual owned record IDs and generations.
Redundant current correspondence is checked in both directions; a checksum alone
never establishes a missing entry or absence of ownership. The private relation
shape follows the source/owned-record closure so document checkout selects the
roster together with the outputs (D1119). Historical payload/provenance selection
continues to use its existing owner.

Only Native publication completion maintains these records, after genuine output
admission and in the same unpublished commit. Its mutations use the original
identity, symbol, allocation and request accounts. The same canonical artifact
contains business and roster patches; checkpoint-fragment charging and admission
clocks remain intact. The existing OrdinaryMetadataWrite guard also protects these
kinds. No caller receives a metadata-writing grant.
