# Phase 3: recorded frontier and complete-selection receivers

## Boundary review

The checked strategy executes genuine Source-tree visits/prunes, but traversal
returns unit and the common adapter returns bare slots. Callback completion is
not recorded predicate coverage. The next required handoff is an actual frontier
that the public, maintained-public and invariant receivers must consume before
admitting a complete selection. This is also prerequisite material for retained
predicate registration; Live's current scope-only opening read cannot supply it.

Live currently delivers business-emission targets. It must eventually gain an
internal managed dependency cause and whole-Parent refresh, preserving its lower
basis, governance, ACK and close owners. Native preparation is not a wake point:
prepared notices must follow exact World selection/adoption, including pending
and generated materialization paths. These facts constrain the successor routing
slice; they do not justify a fake effect, target or parallel subscription owner.

Keep the current actual Source/root pair and admitted sessions. Capture only the
regions actually visited: Branch, SourceMatched, SourceExcluded or Pruned. A
pruned disposition can originate only from the private successful checked-summary
dispatch; providers receive no recorder or arbitrary coverage assertion door.
Interrupted callbacks and decoder/control refusals cannot seal a complete cut.
Storage and verification must scale with the frontier, never root cardinality
or the descendants of a pruned region.

The structural cut requires exactly one disposition per region, its actual root,
an expanded recorded parent for each nonroot record, and a record for every actual
child of each expanded region. No orphan, duplicate, missing child or descendant
of a pruned node is valid. Every expanded Source-bearing node has Matched or
Excluded, including prefix internal nodes. Selected slots must biject with the
actual Matched dispositions. SourceTree already proves the underlying connected
acyclic Source universe and qualified summaries; do not reconstruct that universe.

Complete-selection legality belongs in worth-proof/managed_access/coverage.rs.
Its concrete structural verifier issues only after the cut checks, using paid
Query lookups/checkpoints. Raw descriptive records carry no authority. One issuer
is private to the actual registered TypedIndexProvider, whose installed Index,
provider and schema correspondence is already checked; its real receiving index
holds the matching authority. A public fresh issuer cannot satisfy that receiver.
There is no public admit(bool/digest), generic authority marker or narrowing issuer.

The namespace alone cannot bind an invocation. Query must verify the actual
borrowed node payload, Source carrier/storage, encoded probe and audience before
consuming a noncloneable candidate outcome. Public audience is the genuine Parent
graph-work session; Native committed and proposed audiences are the genuine
ManagedIndexSourceRead and distinct posture. Preserve existing installation,
scope/principal, Product basis/currentness, plan/parameters, ordering/result shape
and request checks. Do not manufacture a public Parent grant for an invariant.

Retain the verified frontier with the existing public managed Source observation
and its already owned Parent context. Physical Node IDs/frontier shape must not
change semantic Source equality/checkpoint identity: identical truth after cache
rebuild remains the same truth. A borrowed invocation frame is real object
correspondence, not a new image stamp. The retained cut does not authorize
dependency narrowing, reuse or mutation eligibility.
