## Boundary brief (completed before implementation plan)

Semantic truth and owners:

- Declaration continuation targets one ordered Many result relation under an
  ExactlyOne root, one exactly-one parent path, no relation predicate, and pinned
  support. Ordering is entirely inside that target child collection.
- Installation continuation_contract resolves the actual compiled relation and
  schema_layout lowers its Native RelatedEntityOrdering index. Native owns its
  actual generation, boundary and finite page.
- Execution application_query/continuation owns the move-only token with exact
  runtime/schema/query/parameter/scope/contract/provider/index generation and
  retained selected World. Readmission checks that actual affinity, admits new
  query controls and fresh governance/independent READ; execute refreshes
  governed authorization before authorized read, compares generation and uses
  the canonical finalizer to issue rows/token/receipt.
- Publication application_entry/query/continuation has ordinary page/resume;
  governed_continuation has page_approved and readmit_resume_approved callback.
  Ordinary page_governed/resume_governed conveniences are missing. Its installed
  capability/operation/current selected principal/scope admission is the existing
  owner to reuse for both optional approved and ordinary governance.
- The token is consumed on denied resume. It retains data and cursor affinity,
  not grant/session authority. Regrant evidence must use independently issued
  genuine tokens, never cloning/fabricating a token or claiming watch-style ACK
  preservation.

Adjacent responsibilities and insufficient proxies:

- Managed indexes currently select ROOT rows; their candidate/refinement receiver
  does not select continuation children. Managed+continuation is deliberately

  lifting these refusals would bypass managed selection in the dedicated page
  reader. Preserve and explicitly qualify that limit.
- No root-result pagination, related managed selector, second cursor authority,
  current-data fallback or historical-generation reconstruction is invented.
  The future shape would require its own declaration/ordering/retention contract.
- Current capability/optional approval and independent READ decide lawful use;
  disclosure influence decides whether hidden inputs may affect order/Pagination.
  A permitted hidden field remains omitted through the normal final projector.
- Matching text/row IDs, old decisions, descriptor copies or cursor ordinals do
  not substitute for the actual retained World, Native ordering generation,
  fresh principal/purpose/current grant and actual result contract.
