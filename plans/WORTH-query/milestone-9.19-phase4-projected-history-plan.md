The existing Native authored_managed_source_selector/history_cursor accepts
actual registered Source programs using the existing scalar-valued Struct-field
and direct endpoint-route grammar. It retains complete conservative canonical
impact candidates; it does not grant Source READ, exact field-path relevance or

membership programs still omit scalar-only history. Existing live-only/typed-gap

   retain the same actual roster/selector affinity, choose Source records using

   pullback. Remove superseded profile checks and includes_entity_kind. Rename
   internal membership-specific packet/catalog names only where meaning changed.

   declared-field and schema-fields-only profiles, and real transaction cases.
   Reuse current Reader/SourceOwner and public medium. Replace the old unsupported

   foreign/generation/cancellation/codec-gap refusals intact.
5. Update Native API/capability/milestone docs precisely, save actual evidence,
   and obtain unconditional independent qa-loop/qa-tests/code-quality-qa gates.
