## Actual boundary

Native admits the applied draft's content before preparing managed Sources.
The preparation and invariant-observation doors retain the actual proposal
interpretation, while a selected rebuild retains its actual immutable root.
Extend these owners, never a coordinate-to-runtime-head resolver. Bind the
logical before/after content directories and schema authorities once on the
interpretation after admission, funded by the original request. Suspension's
logical after image reads retained before truth even though its physical fields
are absent. Rematerialization may acquire retained content only through the
existing genuine restoration-origin check. A mode or copied descriptor cannot
supply that authority.

The actual Source membership tickets, audience checks, kind checks, field
locators and original Source allowance remain prerequisites. Derive the expected
format from the Native field declaration and its existing codec alias. Extend
the existing paid field-reference interpreter rather than inventing a Query
format-ID resolver. Native acquisition must charge the original SDK and Source
allowance once each and preserve their distinct typed failures. Content read
failures extend the existing managed Source preparation refusal; they do not
change the pure derived-relation failure vocabulary.

Query's complete projected-field carrier may retain the actual Native frame
beside its ContentRef scalar. That frame shares Native's immutable backing and
original grant; Query creates no bytes table or serialized byte cache. Both
Source read postures and nested projected endpoints must populate this carrier.
The completed public Source runs ordinary result-tree materialization. Its actual
pinned Native projection must therefore retain content at the existing field
projection, preserving that selected root and typed read refusals. Rebuilding a
second Source roster or filling bytes from runtime head is not an alternative.
Existing field dependencies and the full ContentRef value carry changes; no
second notification system is needed. Compare exact admitted bytes when proving
Source equality, and refuse inconsistent same-identity material. A cached digest
may reject equality but cannot certify it alone.

Demanded preimages currently retain exact observed field values, not content
custody. Extend their existing retention seal with actual Native frames captured
from the original admitted basis, checked against the observed record, kind,
locator and identity. Include complete frame length in the installed demand's
byte bound. Correction must attach these original frames before the existing
pre-publication domain-value seal; it must neither resolve against the current
head nor re-encode a rendered old value.

Committed changes retain Native's actual canonical envelope. Its live admitted
content directory is complete; serialized introduced records alone are not.
An owner-side field-bound historical read must select the exact authoritative
patch location, never accept a caller's digest as authority. An envelope without
complete admitted custody returns a typed refusal. Native checkpoint and journal
reconstruction continue admitting durable frames and field closure before root
selection. Restored bytes do not mint live managed Source history: preserve the
existing IncompleteManagedSourceHistory refusal and do not import replay into
ordinary Query/Decl/Host. Branch-root checkpoints currently enumerate live branch
heads, so a retained Query preimage must not be claimed as a separately recovered
Native root. Existing historical gaps remain explicit.

## Checkpoint reading verified during implementation

An ordinary Source query can read recovered Native content immediately, but a
maintained public open/rebuild requires an actual live managed Source image. A fresh
application checkpoint does not supply that World image; the existing Native
rebuild port returns RootUnavailable. Do not turn recovered bytes into live Source
history. The consuming court must assert this exact pre-edit refusal and unchanged
selected commit, then use a genuine authored content edit with the already-declared
AdmitRebuild posture. That existing owner cold-acquires actual committed/proposed
loans and publishes genuine current Source material. Keep an unchanged recovered
row and compare both candidate sets to the independent integer input-list oracle,
then explicitly rebuild/select. This is reconstruction of current data through an
authorized transition, not restoration of older Source observations or correction
occurrences. The same reviewer independently traced and accepted this reading.
