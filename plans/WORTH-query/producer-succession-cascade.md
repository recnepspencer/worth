# Producer succession source-scope retirement

Issue #42, D1069. Adversarial constraint: a generator removes one generated
source while other branches remain live; the candidate must retire exactly every
live opted-in publication transitively owned by that removed source, with no
orphan, foreign retirement, or merged provenance.

## Boundary review

Query's real installed producer path supplies the existing running succession
admission, exact predecessor custody and completed candidate roles. Native owns
actual deletion effects, canonical predecessor membership, current route history,
source ownership, closure and atomic commit. #39's closure owner must accept a
set of roots without weakening its authored-birth gate. No caller list, naming
convention or reference establishes closure membership. Independent publications
are excluded; an independent parent may still remove a member owning opted-in
children. Installations with no opted-in producers keep their existing path.

Canonical history must distinguish producer-triggered retirement from authored
retirement. Each retired route retains its own producer, dependency, meaning,
birth and predecessor, alongside the generator's surviving Preserve publication.
Cold validation must check the group, not trust a serialized roster. The existing
request work and memory admission fund all selection and capture.

## Implemented history contract

The generator remains the primary Preserve origin. A separate canonical
producer-retirement event contains the exact deleted predecessor anchors and
each descendant's ProducerRetirement origin. Its issuer is derived from the
authentic running succession, with exact commit/ordinal and owner checks in
worth-proof. Cold Native readmission independently recomputes the closure from
the generator before image, checks provenance, membership and actual deletions,
and refuses changed, missing or foreign group data. Absent-group canonical
payload encodings and authoritative digest inputs remain unchanged. Canonical
artifact format is 3 and Native checkpoint magic is WORTH-REL-CHK15; unsupported
development formats refuse, with no migration promise.

Ordinary succession retains the existing charged dependent-source eligibility
probe. It does not repeat that scan or walk the complete publication catalog
when no owning scope is removed. Only an actual live owned dependent enters
full closure preparation; the old refusal subject is retained when the candidate
supplies no dependent retirement.
